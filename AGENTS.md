This repo uses Typescript, with Bun as the package manager, script runner, test runner and TypeScript runner for development (`bun install`, `bun run <script>`, `bun run test`). Run TypeScript against the sources with `bun --conditions=job-scraper-source <file>` (the condition points the package's `#platform` import at `src/` rather than `dist`). Run tests with `bun run test`, not a bare `bun test`: the script adds the condition plus `--isolate`, which the tests rely on. The published package stays runtime-agnostic (plain ESM built by `tsc`, for Node 22+, Bun, Deno and browsers), so don't use Bun-only APIs outside tests and dev scripts. I highly prefer to avoid adding additional third-party dependencies to my project, unless it abstracts very complex functionality; otherwise add a utility.
