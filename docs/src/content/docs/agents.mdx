The repository includes a portable [`job-scraper` skill](https://github.com/chrisdothtml/job-scraper/tree/main/skills/job-scraper/SKILL.md) following the [Agent Skills specification](https://agentskills.io/specification). Install it with the [Skills CLI](https://github.com/vercel-labs/skills), which handles discovery and installation for supported agents:

```sh
npx skills add chrisdothtml/job-scraper --skill job-scraper
```

Choose your agent(s) in the installer. Installation is project-local by default; add `--global` to make the skill available across projects. Use `--agent <agent-name>` to target a particular agent; see the CLI's [supported agents](https://github.com/vercel-labs/skills#supported-agents). The skill folder is also included in the npm package tarball.

### Use the skill

You can ask general questions about job listings, or a specific role:

```
/job-scraper does netflix have any remote engineering roles?
```

```
/job-scraper does anthropic have any devxp roles in the bay area?
```

```
/job-scraper would this role be a good fit for me? https://job-boards.greenhouse.io/[...]
```

## How agents use the skill

Agents primarily interact with this package via the [CLI](/job-scraper/cli/), but they also are given additional instructions for things like [efficiently fetching many postings](/job-scraper/guides/efficiency/).
