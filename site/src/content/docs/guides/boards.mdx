Constructors are properties of [scrapers](/job-scraper/reference/#scrapers); their names form [ScraperName](/job-scraper/reference/#ScraperName). **Discoverable** means name-derived slug probing works. Other boards can still resolve through recognized URLs, known registry records or explicit board identity; search can locate non-derivable multi-tenant slugs.

| Scraper                  | Discoverable | Browser CORS | Notes                                      |
| ------------------------ | ------------ | ------------ | ------------------------------------------ |
| `GreenhouseScraper`      | Yes          | Yes          | Embedded boards and `gh_jid` hints         |
| `AshbyScraper`           | Yes          | Yes          |                                            |
| `LeverScraper`           | Yes          | Yes          |                                            |
| `WorkableScraper`        | Yes          | No           |                                            |
| `SmartRecruitersScraper` | Yes          | Yes          | PascalCase slugs                           |
| `RipplingScraper`        | Yes          | Yes          |                                            |
| `WorkdayScraper`         | No           | No           | `tenant.pod.site`, e.g. `autodesk.wd1.Ext` |
| `GitHubScraper`          | No           | No           | iCIMS-backed, single-company scraper       |
| `GoogleScraper`          | No           | No           | Single-company scraper                     |
| `NetflixScraper`         | No           | No           | Single-company scraper                     |
| `NvidiaScraper`          | No           | No           | Eightfold-backed, single-company scraper   |
| `ShopifyScraper`         | No           | No           | Single-company scraper                     |
| `UberScraper`            | No           | No           | Oracle Fusion Recruiting Cloud-backed      |

Browser support depends on the board’s current cross-origin policy. Node does not enforce browser CORS. See [browser fallback](/job-scraper/guides/browser/).
