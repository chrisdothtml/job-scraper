## Install

```sh
npm i @chrisdothtml/job-scraper
```

Use the equivalent `bun add`, `pnpm add`, `yarn add`, or `deno add npm:` command. The package has no runtime dependencies and supports Node 22+, Bun, Deno and browsers through a bundler. Browser board access depends on [CORS support](/job-scraper/guides/browser/).

<h2 id="rendering">Render a posting for LLM input</h2>

Fetch with [fetchJob](/job-scraper/reference/#fetchJob), then use [renderScrapedPosting](/job-scraper/reference/#renderScrapedPosting) to get readable Markdown. This self-contained example uses synthetic source data so it runs without a network request:

<Snippet file="rendering" />

Complete mode is the default: all parsed JSON fields and outer job metadata are represented, including empty containers and extra application/source data. Compact mode selects and deduplicates posting prose for shorter prompts; it may omit meaningful fields. Neither representation is a lossless serialization. The original job object and **exact content string** remain in `raw` and `raw.content`; keep them alongside the Markdown for provenance. HTML conversion is not a sanitizer. Treat scraped content as untrusted when rendering it in a frontend or building model prompts.

Set `postingUrl` if the source’s `job.url` points to an application form and you know the public posting URL. It changes the displayed link without altering the source object.
