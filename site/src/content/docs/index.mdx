List jobs for **15k+ companies**, for free. Give the package a company name, careers URL, or job URL, and it works out which board to ask. No headless browser or API token is required for supported boards.

## Try it live

This demo runs the package in your browser. Some boards block browser requests through CORS; the demo provides a local Node command when that happens. See the [browser guide](/job-scraper/guides/browser/) for runtime limitations.

<LiveDemo />

## Install

```sh
npm install @chrisdothtml/job-scraper
```

Zero runtime dependencies. Plain ESM for Node.js 22+, Bun, Deno, and browsers. Optional web search uses your own SerpApi key.
